# odin-rock-paper-scissors
The Odin Project - Rock Paper Scissors

Rock, paper, scissors game with a Wild West twist.

## About the game
A simple Rock, Paper, Scissors game built with a graphical interface.  
The game includes sound effects, background music controls, and visual elements like health hearts and character sprites.

It was created as a way to practice:
- JavaScript logic and DOM manipulation
- CSS layout (Flexbox, positioning, overlays)
- UI interactions and game state handling

## Features

- Rock, Paper, Scissors gameplay vs computer
- Score tracking system
- Health system (hearts for player and enemy)
- Sound effects (gunshots + toggle on/off)
- Background music with controls
- End screen with "Play Again" option
- Wild West themed UI

## Purpose

Built as part of **The Odin Project curriculum**, focusing on strengthening core front-end fundamentals through a small interactive game.
